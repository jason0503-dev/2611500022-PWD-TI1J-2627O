# pertemuan-06

## PENGEMBANGAN

1. Mengubah index.html menjadi index.php agar halaman dapat menjalankan PHP melalui server
2. Menambahkan variabel dan konstanta PHP untuk menyimpan data mahasiswa, mata kuliah, dan informasi lainnya.
3. Menerapkan data PHP yaitu string, integer, float, boolean, dan NULL.
4. Menerapkan percabangan switch-case-default untuk menentukan fokus program studi.

## PENGUJIAN

1. Melakukan pengujian Laragon agar dapat membuka halaman localhost
2. Pengujian variabel data mahasiswa agar tampil dan sesuai
3. menggunakan data string, integer, float, boolean, dan NULL.
